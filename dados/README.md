# 📁 Runtime Data Directory (`dados/`)

This directory is used internally by **AgentDeck** for temporary and runtime storage during user sessions.

---

## 🔒 Privacy and Retention Policy

For privacy and technical compliance reasons, the contents of this folder are **ignored by version control (`.gitignore`)**:

1. **Audio Recordings (`.wav`):**
   - Audio captured by the microphone is recorded temporarily for processing by the Whisper engine.
   - **Immediate Discard:** As soon as neural transcription is completed, the `.wav` file is **immediately deleted** from disk. Zero voice retention.

2. **Attachments and Multimodal Captures (`anexos/`):**
   - Images pasted (`Ctrl+V`), files dragged over a window, or attached via the window header button (and via the "New task" form) to provide context for agents.
   - **5-Session Retention:** AgentDeck keeps attachments only from the 5 most recent sessions. Files from older sessions are automatically purged at startup.

3. **Long Prompts (`prompts/`):**
   - Extended prompts sent to the Antigravity CLI that exceed the safe limit of the Windows command line are written to temporary text files and passed via directory reference.

4. **Session History (`sessions.json`):**
   - Local record of alphanumeric identifiers of the latest active sessions for lifecycle management and file purging.

5. **Tasks (`tarefas/`):**
   - The tasks desk keeps one `<project>.json` per project (tasks, reports, and history) and, for each task that opens a new tab, the brief (`<project>-<id>-brief.md`) and feedback (`-feedback.md`) files that the agent reads from disk.
   - **They stay outside the user's repository** and are not deleted when removing the project.

6. **Claude Hooks (`hooks/`), `crash.log`, and `.agentdeck.lock`:**
   - Generated by the app: start/end-of-turn hooks configuration, crash log (`crash.log`, rotated when exceeding 256 KB), app log (`agentdeck.log`, rotated when exceeding 2 MB), and the lock preventing a second window on the same folder.
