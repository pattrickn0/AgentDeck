# 🗂️ Agent Workspace (`workspace/`)

This directory is the **original development sandbox (workspace)** for artificial intelligence agents (**Claude Code**, **Google Antigravity**, and others) operating through **AgentDeck**. Today, the center of the app is **projects**: each project is a folder chosen by the user, and its tabs run there. `workspace/` continues to exist as the app folder to which a legacy configuration is migrated (`Config::migrate_legacy`) and where the app creates `AGENTS.md`.

---

## 🛡️ Principle of Isolation

To prevent agents from making accidental changes to the infrastructure files of the AgentDeck application itself (`crates/`, `Cargo.toml`), agent tabs run in the folder of the **project** in which they were opened (and, in a desk task, in its own worktree, `<repo>/.agentdeck/worktrees/<id>`), not in the app folder.

- Any file, script, repository, or code generated by AIs during their tests or tasks is created in the project or task folder.
- With no project open, the center of the app asks for a folder; users who had only the legacy workspace receive a project pointing to it on first launch.

---

## 📄 Agent Instructions (`AGENTS.md`)

The [`AGENTS.md`](./AGENTS.md) file in this folder is **generated by the app** (the block between `<!-- agentdeck:start -->` and `<!-- agentdeck:end -->` is rewritten on every launch) and read by AI CLIs at startup. In project folders, the app only updates the block in an already existing `AGENTS.md`. It instructs agents on:
1. Their active agent name (via the `AGENTDECK_AGENT` environment variable).
2. The shell command `ask-agent <agent> "message"` to consult another agent.
3. Guidelines for exchanging opinions, peer code review, and collaborative synthesis of tasks.
